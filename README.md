💈 Barbershop-BE
==========

Backend REST API for managing barbershop appointments, built with Java Spring Boot.

The system handles authentication, appointment scheduling, feedback management, and role-based access for clients and barbers.

This backend powers the frontend application by providing secure REST endpoints, database persistence, and business logic.

The project demonstrates REST API design, layered architecture, authentication, and database integration using modern Java backend technologies.

🚀 Features
===========

### 🔐 Authentication

User login system

Role-based access (Client / Barber)

Secure route protection

### 📅 Appointment Management

Schedule new appointments

View upcoming appointments

View past appointment history

Manage personal bookings

### 👤 Client Features

* Create and manage appointments

* View previous services

*   Leave a review of the barbershop by rating it from 1 to 5 stars and adding a comment. Both rating and comment will appear on the homepage.

### ✂️ Barber Features

* View scheduled appointments

* Manage upcoming bookings

###  Feedback System

* Clients can rate their experience

### 🛠️ Technologies Used

* Java

* Spring Boot

* Maven

* Lombok

* JPA

* Hibernate

* MySQL

* REST API Architecture

* Docker
